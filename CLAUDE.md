# Инструкции для Claude Code

## Язык общения
- Общаемся на русском

## Рабочий процесс
- Все проекты делаем пошагово
- После каждого шага пользователь присылает скриншот для проверки
- Никогда не удалять сообщения пользователя

## n8n Cloud
- Пользователь обновляет воркфлоу вручную через copy-paste в n8n Cloud
- Не предлагать импорт файлов — вместо этого выводить готовый текст/код для копирования прямо в чат

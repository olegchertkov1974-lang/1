# Инструкции для Claude Code

## Язык общения
- Общаемся на русском

## Рабочий процесс
- Все проекты делаем пошагово
- После каждого шага пользователь присылает скриншот для проверки
- Никогда не удалять сообщения пользователя

## n8n Cloud
- Пользователь обновляет воркфлоу вручную через copy-paste в n8n Cloud
- Не предлагать импорт файлов — вместо этого выводить готовый текст/код для копирования прямо в чат

## Безопасность ключей
- НИКОГДА не хранить API ключи и секреты в JSON workflow файлах
- Вместо этого использовать: environment variables, credentials/secret storage, .env, приватные настройки n8n
- В workflow использовать плейсхолдеры (YOUR_API_KEY) или ссылки на переменные окружения
